# Customer Data Quality & MIS Reporting Automation

## Overview

Customer Data Quality & MIS Reporting Automation is a Python-based analytics project designed to automate customer and sales data validation, data cleaning, exception tracking, and management information system (MIS) reporting.

The project demonstrates how data quality checks and reporting automation can help organizations maintain reliable datasets and improve the consistency of business reporting.

## Business Problem

Business reports depend on accurate, consistent, and complete data. Missing values, duplicate records, inconsistent formats, and invalid entries can affect reporting accuracy and decision-making.

This project focuses on identifying data quality issues, preparing cleaner datasets, and organizing exceptions to support reliable customer and sales reporting.

## Objectives

- Identify missing, duplicate, and invalid records.
- Apply data cleaning and validation checks.
- Track data quality exceptions.
- Automate repetitive data preparation and reporting tasks.
- Support consistent customer and sales MIS reporting.
- Improve the reliability of data used for business analysis.

## Key Capabilities

- Customer and sales data quality checks
- Data cleaning and validation
- Duplicate and missing-value analysis
- Exception tracking
- Automated reporting workflows
- Interactive reporting through Streamlit

## Technology Stack

- **Python** — data processing and automation
- **Pandas** — data cleaning and manipulation
- **Streamlit** — interactive application interface
- **Git and GitHub** — version control and project management

## Business Applications

This type of workflow can support sales operations, customer data management, recurring MIS reporting, and data quality monitoring. Reliable data helps analysts spend less time correcting records and more time producing useful business insights.

The repository contains project data and application code used for data quality checks and reporting automation. Explore the folders in the repository for the implementation and supporting files.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/arjavianup523/Customer-Data-Quality-MIS-Automation.git
cd Customer-Data-Quality-MIS-Automation
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.venv\Scripts\Activate.ps1
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

To launch the Streamlit application, use the actual dashboard entry-point file in the repository:

```bash
streamlit run dashboard/app.py
```

If your dashboard file is located elsewhere, replace the path with its actual location.

This project demonstrates practical data analytics skills in data cleaning, validation, exception tracking, and reporting automation. It connects technical data preparation with the business need for accurate and dependable management reporting.
